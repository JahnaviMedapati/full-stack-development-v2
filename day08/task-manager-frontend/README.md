# React Task Manager

A simple Task Manager frontend built with React and Vite.

## Features

- Display tasks
- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Empty-state message when there are no tasks
- Controlled form input
- Component-based architecture

## Technologies

- React
- JavaScript
- Vite
- CSS
